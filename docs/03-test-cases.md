## TC-001 - Login exitoso con usuario válido

| Campo | Descripción |
| ID | TC-001 |
| Módulo | Login |
| Requisito relacionado | REQ-002 |
| Prioridad | Alta |
| Tipo de prueba | Funcional positiva |
| Precondición | El usuario debe estar en la página de login. |
| Datos de prueba | santiago31469628@gmail.com / 1234567 |

### Pasos

1. Ingresar el usuario `santiago31469628@gmail.com`.
2. Ingresar la contraseña `1234567`.
3. Hacer clic en el botón 'SING IN'.

### Resultado esperado

El sistema debe permitir el acceso y mostrar los detalles de la cuenta junto con el historial de los pedidos realizados.

### Resultado obtenido

Pendiente de ejecución.
