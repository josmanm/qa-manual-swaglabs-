# Plan de Pruebas

## Aplicación bajo prueba

Sauce Demo.

## Objetivo de las pruebas

Validar que los flujos principales de la tienda online funcionen correctamente desde el inicio de sesión hasta la finalización de una compra.

## Alcance

Se probarán los siguientes módulos:

- Login.
- Catálogo de productos.
- Filtros.
- Carrito de compras.
- Checkout.
- Confirmación de compra.
- Logout.

## Fuera de alcance

- Pruebas de rendimiento.
- Pruebas de seguridad avanzadas.
- Pruebas automatizadas.
- Pruebas de base de datos.
- Pruebas de API.

## Ambiente de prueba

- Sistema operativo: Windows 11.
- Navegador: Microsoft Edge.
- Aplicación: Sauce Demo.
- Tipo de prueba: Manual.

## Criterios de entrada

- La aplicación debe estar disponible.
- El navegador debe estar actualizado.
- Deben existir usuarios de prueba.
- El tester debe tener acceso a la aplicación.

## Criterios de salida

- Los casos de prueba críticos fueron ejecutados.
- Los defectos encontrados fueron documentados.
- Se generó evidencia de las pruebas fallidas.
- Se elaboró el reporte final de pruebas.
