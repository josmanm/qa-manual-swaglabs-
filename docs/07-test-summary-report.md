# Reporte Final de Pruebas

## Resumen

Se ejecutaron pruebas manuales sobre la aplicación Swag Labs / Sauce Demo, enfocadas en los flujos principales de una tienda online.

## Alcance ejecutado

- Login.
- Catálogo.
- Filtros.
- Carrito.
- Checkout.
- Logout.

| Métrica | Cantidad |
|---|---|
| Casos diseñados | 15 |
| Casos ejecutados | 15 |
| Casos aprobados | 14 |
| Casos fallidos | 1 |
| Casos bloqueados | 0 |
| Defectos reportados | 1 |

## Defectos encontrados

| ID | Título | Severidad | Estado |
|---|---|---|---|
| BUG-001 | Mensaje poco claro en checkout sin código postal | Media | Open |

## Conclusión

La aplicación permitió completar correctamente los flujos principales de compra. Sin embargo, se identificó una oportunidad de mejora en la claridad de los mensajes de validación del checkout.
