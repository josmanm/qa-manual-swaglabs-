# Análisis de Requisitos

Como la aplicación Sauce Demo es una aplicación demo, los requisitos fueron inferidos a partir del comportamiento esperado de una tienda online.

## Requisitos funcionales

| ID | Módulo | Requisito |
|---|---|
| REQ-001 | Register | El sistema debe permitir crear una cuenta para realizar login |
| REQ-002 | Login    | El sistema debe permitir el inicio de sesión con credenciales válidas. |
| REQ-003 | Login    | El sistema debe mostrar un mensaje de error cuando el usuario ingresa credenciales inválidas. |
| REQ-004 | Catálogo | El sistema debe mostrar la lista de productos disponibles después del login. |
| REQ-005 | Catálogo | El sistema debe permitir ordenar productos por nombre y precio. |
| REQ-006 | Carrito  | El sistema debe permitir agregar productos al carrito. |
| REQ-007 | Carrito  | El sistema debe permitir eliminar productos del carrito. |
| REQ-008 | Checkout | El sistema debe solicitar nombre, apellido y código postal para continuar la compra. |
| REQ-009 | Checkout | El sistema debe mostrar un resumen de la compra antes de finalizar. |
| REQ-010 | Checkout | El sistema debe permitir finalizar una compra exitosamente. |
| REQ-011 | Logout   | El sistema debe permitir cerrar sesión correctamente. |
