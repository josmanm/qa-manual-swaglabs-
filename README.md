# QA Manual Testing Project - Swag Labs

Este repositorio contiene la documentación de pruebas manuales realizadas sobre la aplicación Swag Labs / Sauce Demo con findes educatiivos y practicos.

## Objetivo

Validar los principales flujos funcionales de una tienda online, incluyendo autenticación, catálogo de productos, carrito de compras, checkout y cierre de sesión.

## Alcance

- Pruebas funcionales.
- Pruebas exploratorias.
- Pruebas de regresión básica.
- Reporte de defectos.
- Matriz de trazabilidad.

## Herramientas utilizadas

- GitHub.
- Markdown.
- Google Sheets / Excel.
- Microsoft Edge.
- Capturas de pantalla.
